# 🎮 PLAYDOGS — DISCORD SERVER SETUP GUIDE
## Step-by-Step Instructions (100% Free)

---

## STEP 1: CREATE THE SERVER

1. Open Discord (download from discord.com if you don't have it)
2. Click the **"+"** button on the left sidebar
3. Select **"Create My Own"**
4. Choose **"For a club or community"**
5. Name it: **PLAYDOGS** or **PLAYDOGS Official**
6. Upload a server icon (use your best PlayDog pixel art image)
7. Click **"Create"**

✅ Server created!

| 🖼️ **Holder** | Green (#2ECC71) | People who own a PlayDog NFT |

| ⭐ **OG Dog** | Yellow (#F1C40F) | First 100 members |
| 🐶 **Pack Member** | Gray (#95A5A6) | Everyone who joins |

### Role Permissions:
- **Founder & Moderator:** All permissions
- **Alpha Dog:** Manage messages, kick/ban, manage channels
- **Everyone else:** Read & send messages only
- **@everyone:** Can't post in #announcements (only admins)

## STEP 4: ADD FREE BOTS

### Bot 1: MEE6 (Welcome Messages + Leveling)
1. Go to **mee6.xyz**
2. Click "Add to Discord"
3. Select your PLAYDOGS server
4. Enable these features:
   - **Welcome Plugin:** Auto-sends welcome message when someone joins
   - **Leveling:** Members earn XP by chatting (gamification!)
   - **Moderator:** Auto-delete spam, bad words

**Welcome Message Template:**
```
🐶 Welcome to the PLAYDOGS Pack, {user}! 🐶

You are member #{memberCount}!

📜 Read the #rules first
👋 Introduce yourself in #introductions
🎁 Check #giveaways for free stuff
😂 Drop your best memes in #memes

Glad to have you in the pack! 🐾
```

### Bot 2: Carl-bot (Reaction Roles)
1. Go to **carl.gg**
2. Click "Invite"
3. Select your PLAYDOGS server
4. Set up **Reaction Roles** in #rules channel:

Post a message like:
```
React to get your roles! 🐶

🐕 — I'm here for the community
💎 — I'm a collector/investor  
🎨 — I'm an artist
😂 — I'm here for the memes
📢 — Notify me about announcements
```

### Bot 3: GiveawayBot (Free Giveaways)
1. Search for **GiveawayBot** on top.gg
2. Invite to your server
3. Use command: `!giveaway 24h 1 winner PlayDog NFT` to start a giveaway
4. Members react to enter
5. Bot picks random winner after time expires

### Bot 4: Wick Bot (Anti-Scam Security)
1. Search for **Wick** on top.gg
2. Invite to your server
3. Wick auto-detects:
   - Scam links
   - Phishing DMs
   - Raid attacks
   - Spam bots
4. CRITICAL for NFT servers (scammers target NFT communities!)

## STEP 7: SERVER SETTINGS

### Important Settings to Change:
1. **Server Settings → Community** → Enable Community Server (unlocks extra features)
2. **Server Settings → Safety Setup** → Set verification level to "Medium" (must have verified email)
3. **Server Settings → Moderation** → Enable AutoMod to catch spam
4. **Server Settings → Overview** → Add server description

## ANTI-SCAM CHECKLIST ⚠️

NFT Discord servers are PRIME targets for scammers. Protect your community:

- [ ] Enable Wick bot for auto scam detection
- [ ] Set verification level to Medium or High
- [ ] Disable DMs from server members (recommend in #rules)
- [ ] NEVER share mint links in DMs
- [ ] Pin official links in #links — tell people to ONLY use those
- [ ] Add "Scam Alert" message: "Our team will NEVER DM you first"
- [ ] Make #report-scams channel so members can flag suspicious activity
- [ ] Disable link embedding for new members (first 10 minutes)
- [ ] Enable Slowmode (5 seconds) in high-traffic channels
