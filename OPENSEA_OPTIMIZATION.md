## STEP 7: METADATA & PROPERTIES

### Make sure every NFT has these properties:
When you upload your NFTs, the metadata JSON should include these traits so buyers can FILTER:

| Property | Type | Examples |
|----------|------|----------|
| Breed | Property | Golden Retriever, Husky, etc. |
| Skin | Property | Normal, Gold, Zombie, Alien, Robot |
| Background | Property | Solid Gray, Cyan Blue, etc. |
| Hat | Property | Crown, Beanie, None |
| Glasses | Property | Shades Dark, Laser Red, None |
| Mouth | Property | Cigar, Pipe, None |
| Rarity Tier | Property | Common, Uncommon, Rare, Super Rare, Legendary, Mythic |
| Rarity Score | Stat | 100-1000 (numeric ranking) |

### Why this matters:
- Buyers can filter by breed, skin type, accessories
- Rare trait filters help collectors find what they want
- OpenSea shows rarity percentages automatically
- Makes your collection look PROFESSIONAL

## STEP 8: UPLOAD YOUR NFTS

### Method A: One-by-One (Small batches)
1. Click "Add Item" on your collection
2. Upload image, name, description, properties
3. Repeat 10,000 times (not recommended lol)

### Method B: Bulk Upload (Recommended)
1. Prepare a CSV/JSON file with all metadata
2. Use OpenSea's bulk upload tool
3. Or use a tool like **NFT-Maker** or **thirdweb** (free tiers available)

### Method C: Smart Contract Direct
1. Deploy your PLAYDOGS.sol contract
2. Use a script to batch mint to your wallet
3. List on OpenSea via the contract

### Naming Format:
```
PlayDog #1
PlayDog #2
...
PlayDog #10000
```

### Description for Each NFT:
```
PlayDog #[NUMBER] — A unique retro pixel art dog from the PLAYDOGS collection. 

Breed: [BREED]
Skin: [SKIN]
Rarity Tier: [TIER]

Part of 10,000 procedurally generated dogs on Ethereum. 
Learn more: [website URL]
```

## STEP 9: PRICING STRATEGY

### Option A: Fixed Price (Recommended for launch)
- Set all dogs at **5 ETH** each
- Simple, clean, professional
- Lower the price later if needed

### Option B: Tiered Pricing
| Tier | Price | Why |
|------|-------|-----|
| Common breeds | 3 ETH | Lower entry point |
| Uncommon | 4 ETH | Slight premium |
| Rare | 5 ETH | Standard price |
| Super Rare | 7 ETH | Clearly premium |
| Legendary | 10 ETH | Exclusive |
| Mythic | 15 ETH | Ultra rare = ultra price |

### Option C: Auction Style
- List rare ones as auctions starting at 1 ETH
- Creates bidding wars and excitement
- Good for the first 10-20 "showcase" dogs

### Recommended Strategy:
1. List 10-20 of your BEST dogs first as auctions (builds buzz)
2. List the rest at fixed prices
3. Promote the auction listings on Twitter
4. Drop prices if sales slow after 2 weeks
